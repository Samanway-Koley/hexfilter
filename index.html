                    FAQ
                    
Hex to CSS filter, answered

                    
Everything you wanted to know about converting a hex color code into a usable CSS filter rule.

                

                

                    

                        
                        

                            
It calculates a chain of CSS filter functions — invert(),
                                sepia(), saturate(), hue-rotate(),
                                brightness() and contrast() — that transforms a pure black
                                pixel into your target hex color. Paste the result on any black icon, SVG or PNG and it
                                visually becomes that color, with no image editing.
                            

                        

                    

                    

                        
                        

                            
Very accurate for most colors. The tool uses an SPSA optimizer that matches the target in
                                both RGB and HSL color space, and it shows a live match percentage plus the computed RGB
                                so you can verify the result before copying.

                        

                    

                    

                        
                        

                            
CSS filters transform existing pixels; they cannot invent color from transparency. The
                                solver assumes a black (#000000) source, which is why icon libraries ship
                                monochrome black glyphs. Start from black and the filter can reach any hue; starting
                                from another color would give the wrong result.

                        

                    

                    

                        
                        

                            
Both 3-digit (#RGB) and 6-digit (#RRGGBB) hex codes, with or
                                without the leading # hash. You can also use the built-in color picker, and
                                the input is case-insensitive.

                        

                    

                    

                        
                        

                            
No. All conversion happens locally in your browser with JavaScript. Nothing is uploaded,
                                stored or tracked, so it is safe to use with proprietary brand palettes.

                        

                    

                    

                        
                        

                            
Copy the generated rule and apply it to your element, for example
                                .icon { filter: invert(43%) sepia(52%) saturate(2344%) hue-rotate(305deg) brightness(95%) contrast(92%); }.
                                Make sure the underlying icon renders black first (color: #000 for font
                                icons, or a black SVG / PNG source).
